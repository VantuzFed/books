# 📚 Книжная полка (Bookshelf)

Современное веб-приложение для ведения личного списка литературы с поддержкой нескольких тем оформления (включая ретро-интерфейс **S.T.A.L.K.E.R. КПК**), поиском, фильтрацией, обложками, описаниями и главными героями.

---

## 🚀 Режимы работы

### 1. Автономный запуск (сейчас, без сборки и серверов)
Файл **`books.html`** является полноценным SPA (Single Page Application) на **Vue 3**:
* Не требует установки `node_modules` или сборки.
* Достаточно просто дважды кликнуть по **`books.html`** или открыть его в любом браузере (`file:///...`).
* Все данные хранятся локально в `localStorage` вашего браузера.
* Доступен экспорт и импорт списка в **JSON** и **CSV**.

### 2. Подготовка к переводу в полноценное веб-приложение (Vite + Vue 3)
В проекте уже подготовлена модульная архитектура:
* `package.json` — зависимости и скрипты (`npm run dev`, `npm run build`, `npm run build:watch`).
* `vite.config.js` — конфигурация сборщика Vite.
* `src/App.vue` и `src/main.js` — модульные компоненты на Vue 3.
* `src/services/storage.js` — изолированный сервис хранения данных.

Когда потребуется поднять dev-сервер:
```bash
npm install
npm run dev
```

### 3. Автобилд (CI/CD & Watch Mode)
* **Автобилд и деплой на GitHub Pages (`.github/workflows/deploy.yml`)**:
  При каждом `git push` в ветку `main` с изменениями фронтенда автоматически запускается GitHub Actions, который собирает Vue 3 проект (`npm ci && npm run build`) и выкатывает готовый бандл из `dist/` на **books.vantuzfed.ru**.
* **Локальный автобилд (watch-режим)**:
  ```bash
  npm run build:watch   # или npm run watch
  ```
  Vite непрерывно отслеживает файлы в `src/`, `public/` и автоматически пересобирает `dist/` при любых сохранениях.

## 🎨 Темы оформления

Переключатель тем расположен в правом верхнем углу интерфейса:

1. **☀️ Светлая (Light)**:
   * Чистый минималистичный дизайн с акцентом на типографику (шрифты Inter и Merriweather).
   * Идеален для чтения при дневном свете.

2. **🌙 Тёмная (Dark)**:
   * Глубокая ночная палитра (Midnight Slate / Navy), снижающая нагрузку на глаза в тёмное время суток.
   * Контрастные мягкие бейджи и аккуратные тени.

3. **☢️ S.T.A.L.K.E.R. КПК (Интерфейс середины 2000-х)**:
   * Аутентичная стилизация под карманный персональный компьютер (КПК) сталкера из культовой трилогии «Тень Чернобыля» / «Чистое Небо».
   * Текстурированный милитари-фон с эффектом ЭЛТ-сканлайнов (scanlines) и виньетированием экрана.
   * Моноширинный армейский шрифт (`Share Tech Mono` / `Courier New`).
   * Янтарная и фосфорно-зелёная подсветка индикаторов и панелей.
   * Тематические статусы задач КПК:
     - `[ЦЕЛЬ: ВЗЯТО]` (В планах)
     - `[В ПРОЦЕССЕ]` (Читаю)
     - `[ВЫПОЛНЕНО]` (Прочитано)
     - `[ОТМЕНЕНО]` (Отложено)
   * **Процедурные звуковые эффекты**: тактильные клики и писки КПК, генерируемые на лету через HTML5 Web Audio API (без внешних аудиофайлов).

## ⚡ Функциональные возможности

* **Два режима отображения**:
  - **▦ Сетка**: визуальные карточки с книжными обложками, описанием и автопоиском.
  - **☰ Таблица**: плотный информативный список для работы с большой библиотекой.
* **Полнотекстовый живой поиск**: мгновенная фильтрация по автору, названию, главным героям, описанию и ссылке с кнопкой быстрой очистки.
* **Интерактивные счётчики**: фильтры со встроенным количеством книг в каждой категории («Все», «В планах», «Читаю», «Прочитано», «Отложено»).
* **Поле «Главные герои»**: отдельное поле для указания ключевых персонажей книги с отображением в карточках и таблице.
* **Поле описания**: развёрнутое текстовое поле с адаптивным ограничением строк и всплывающими подсказками.
* **Автопоиск обложек**: автоматический подбор обложек книг по автору и названию через API Open Library и Google Books.
* **Импорт и Экспорт**:
  - Выгрузка всей библиотеки в JSON и CSV одним кликом.
  - Умный импорт с валидацией и фильтрацией дубликатов.
  - Кнопка «Копировать JSON» в буфер обмена.
* **Демо-книги**: быстрый старт с готовой подборкой классики.
* **Горячие клавиши**: клавиша `Escape` закрывает открытые модальные окна.

## 🛠 План перехода на полноценный клиент-сервер (Roadmap)

1. **Фронтенд**: переход с автономного `books.html` на сборку через Vite (`src/App.vue`).
2. **Бэкенд**:
   - Создание легковесного REST API (FastAPI / Express / Go).
   - Эндпоинты: `GET /api/books`, `POST /api/books`, `PUT /api/books/:id`, `DELETE /api/books/:id`.
3. **Хранилище**:
   - В `src/services/storage.js` методы `getBooks()` и `saveBooks()` заменяются на `fetch('/api/books')`.
   - База данных: SQLite (для локального/однопользовательского сервера) или PostgreSQL (для облака).
4. **Авторизация (по желанию)**: добавление многопользовательского режима и синхронизации между устройствами.
